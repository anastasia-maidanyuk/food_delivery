# 🥗 DeliveryDash — Платформа замовлення їжі

Сучасний Full-stack додаток (PERN stack) для замовлення їжі з різних ресторанів. Проект включає динамічне меню, систему кошика з розрахунком знижок та адаптивний інтерфейс.

---

## ✨ Основні можливості

* **🏪 Мульти-магазинність:** Перегляд списку доступних магазинів та їх унікального меню.
* **🛒 Розумний кошик:** Додавання страв, зміна кількості, автоматичний підрахунок вартості.
* **🎫 Система купонів:** Можливість застосувати промокод (наприклад, `WELCOME10`) для отримання знижки.
* **🔍 Фільтрація та сортування:** Пошук страв за категоріями та сортування за ціною (від дешевих до дорогих).
* **📱 Mobile First:** Повністю адаптивний дизайн (MUI Grid & Drawer) для комфортного замовлення зі смартфона.

## 🏗 Структура бази даних

Проект використовує 5 основних таблиць:
1.  `shops` — Назва, опис, рейтинг, URL зображення.
2.  `products` — Страви, прив'язані до конкретного магазину (`shop_id`).
3.  `coupons` — Промокоди зі терміном дії та відсотком знижки.
4.  `orders` — Дані про клієнта та загальна сума.
5.  `order_items` — Деталізація товарів у кожному замовленні.

## 🚀 Як запустити проект локально

### 1. Клонування репозиторію
```bash
git clone [https://github.com/your-username/your-repo-name.git](https://github.com/anastasia-maidanyuk/food_delivery.git)
cd your-repo-name

Налаштування Backend

Перейдіть у директорію сервера (наприклад, ./backend):
npm install

Створіть файл .env у папці бекенду:
PORT=3000
DATABASE_URL=postgres://postgres:password@localhost:5432/delivery_db

Наповніть базу початковими даними:
node seed.js

Запустіть сервер:
npm run dev

Налаштування Frontend

Перейдіть у директорію клієнта (наприклад, ./frontend):
npm install

Створіть файл .env у папці фронтенду:
VITE_API_URL=http://localhost:3000

Запустіть клієнт:
npm run dev
